# i18n: Indonesia dan English

String UI tinggal di `lib/shared/l10n/arb/`:

- `app_id.arb`: template (bahasa Indonesia, default app).
- `app_en.arb`: English.

`flutter gen-l10n` (`just l10n`) menghasilkan `AppLocalizations` di
`lib/shared/l10n/generated/` (di-commit, dikecualikan dari analyzer).
`flutter pub get` juga memicu generate karena `generate: true` di pubspec.

## Memakai di widget

```dart
import 'package:droid/shared/l10n/index.dart';

Text(context.l10n.signInTitle)
Text(context.l10n.homeGreeting(user.name))   // placeholder
```

Pesan validator dan error juga lewat l10n: `Validators.required(l10n.validationRequired)`,
`describeAuthError(error, l10n)`, `describeError(error, l10n)`.

## Menambah string

1. Tambah key di `app_id.arb` (dan `@key` bila ada placeholder), lalu di
   `app_en.arb`.
2. `just l10n`.
3. Pakai `context.l10n.keyBaru`.

## Menambah bahasa

1. Buat `app_<kode>.arb`.
2. Tambah `Locale` di `AppLocales` dan `FSelectTile` di
   `features/select_locale/ui/locale_selector.dart`.
3. Pastikan forui punya `FLocalizations` untuk kode itu; jika belum, tambahkan
   delegate fallback.

## Pilihan user

`localeProvider` (`features/select_locale`) menyimpan kode bahasa di
`KeyValueStore` key `locale`; `null` berarti mengikuti sistem. `App` meneruskan
nilainya ke `MaterialApp.locale`.
